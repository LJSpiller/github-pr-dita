Resolving Merge Conflicts

Reconcile competing branch changes when target branch updates collide with proposed edits.

Merge conflicts occur when overlapping lines are modified independently across branches.

  1. Fetch the latest changes from the default branch into your working environment.
  2. Rebase or merge the target branch into your feature branch locally.
  3. Open conflicting files, locate the conflict markers (<<<<<<<), and select the correct code or text block.
  4. Stage the resolved files and complete the merge commit.
  5. Push the updated branch history to update the active pull request automatically.
