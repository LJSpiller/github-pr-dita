Reviewing a Pull Request

Evaluate proposed changes, leave line-by-line feedback, and submit an approval or change request.

You must have read access to acme-docs/knowledge-base.

Warning:
Force-pushing to a shared branch overwrites commit history and can break active code reviews for other team members.
  1. Navigate to the Pull Requests tab in GitHub.
  2. Select the pull request you want to review and open the Files changed tab.
  3. Hover over a specific line of code or Markdown and click the plus icon to add an inline comment.
  4. Verify that required status checks and code owner approvals meet internal repository policy prior to merging.
  5. Click Review changes and select one of the following submission types:
    • Comment: General feedback without explicit approval or rejection.
    • Approve: Confirms the changes are ready to merge.
    • Request changes: Requires feedback resolution before merging (Enforced for repository maintainers).
