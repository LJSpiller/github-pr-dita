Creating a Pull Request

Initiate a formal review request to propose branch changes into the primary repository.

Ensure all local commits are pushed to your topic branch in acme-docs/knowledge-base.

Important:
Direct commits to the default branch are blocked by repository protection rules. All changes must originate from a pull request.
  1. Navigate to the repository homepage in GitHub.
  2. Click Compare & pull request alongside your recently pushed branch.
  3. Provide a descriptive title and fill out the pull request body template.
  4. Assign relevant code owners and reviewers, then click Create pull request.
