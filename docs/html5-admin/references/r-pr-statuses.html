Pull Request Status Indicators

Reference table of continuous integration status indicators and merge readiness states.

Status Badges

State Description Required Action
Draft PR is open for active editing and testing. Mark as ready for review when complete.
Checks Pending Automated continuous integration linters are running. Wait for build pipeline completion.
Changes Requested A designated reviewer requested updates. Address feedback and re-request review.
